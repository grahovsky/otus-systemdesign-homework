## Исходные параметры

| Параметр | Значение | Как используем |
|---|---|---|
| MAU | 3 000 000 | база для **броней** |
| DAU | 300 000 | база для **чтения** (поиск, карточки) |
| Броней на пользователя | 1 / месяц | `брони/мес = MAU × 1` |
| Peak Factor | **×5** | сезон отпусков; **не** множим ещё раз на «вечер» |

```
брони/сутки     = 3 000 000 × 1 / 30  = 100 000     ← CONFIRMED
RPS_avg         = N_сутки / 86 400
RPS_peak        = RPS_avg × 5
```

### Принятые допущения

| # | Допущение | Зачем |
|---|---|---|
| A1 | «1 бронь / пользователя / мес» = **на MAU** | период совпадает с MAU. Конверсия DAU ≈ 33% — следствие условия, не «реализм OTA» |
| A2 | Каталог **50 000** объектов × **3** room types | региональный Booking; слоты — **скользящее окно 365 дней**, не накопление за 3 года |
| A3 | Create/hold = **1.5×** confirmed | abandon + `SOLD_OUT`. Confirmed = 100k/сутки → **150k create+hold** |
| A4 | До оплаты доходят **120k**/сутки; cancel после confirm **10%** | 10k cancel/сутки |
| A5 | Browse на DAU: **5** autocomplete + **8** GraphQL search + **4** карточки + **4** календаря | fan-out сессии; GraphQL сам батчит поля карточки в выдаче |
| A6 | После confirm: **5** poll `GET /bookings/{id}` | контракт [payment.md](../../hw_02/solution/api/payment.md); SSE вне scope |
| A7 | Search: **20** thumbnails × **30 КБ**; карточка: **10** фото × **150 КБ** | основной egress. JSON API **1–5 КБ** |
| A8 | Медиа: 20 фото/объект × 200 КБ | origin object storage; раздача через CDN (уже в ДЗ 3) |
| A9 | Кэш search **70%** hit (TTL 60 с); карточка **80%** hit | [кэш ДЗ 3](../../hw_03/solution/README.md#4-кэширование) |
| A10 | Рост каталога/аудитории **+20%/год** | критерий «учтен рост»; пик сезона уже в ×5 |
| A11 | Hold TTL **15 мин** | [ADR-0003](../../hw_02/solution/arc42/adr/0003-inventory-soft-hold.md) |
| A12 | 16 шардов Inventory/Booking из ДЗ 3 — **дизайн на рост, не day-1 ёмкость** | write RPS слишком мал, чтобы окупить 16 managed-кластеров |

Партнёрский write (аллотмент/тарифы) ~50k апдейтов/сутки ≈ 0.6 RPS — шум, дальше не тащим.

Схема fan-out: [`diagrams/rps-fanout.puml`](diagrams/rps-fanout.puml).
