## 1. План нагрузочного тестирования

_Профиль нагрузки — из [`sizing.md`](sizing.md#1-расчёт-rps); сценарии: smoke, load, главный
сценарий-риск системы, stress, spike, soak — с критериями успеха, привязанными к порогам из
[`observability.md`](observability.md)._

## 2. Chaos-эксперименты

_2–3 эксперимента, каждый проверяет отдельный механизм отказоустойчивости из
[`reliability.md`](reliability.md) (не один и тот же способ отказа три раза): steady state,
гипотеза, blast radius, метод, наблюдаемое, критерий rollback, ожидаемый вывод._
