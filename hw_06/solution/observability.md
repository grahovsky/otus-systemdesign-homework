# 8. Observability

> Часть [решения ДЗ 6](README.md).

## 1. Ключевые метрики (10–15)

_RED на критичных сервисах, USE на ресурсах под ними, 2–3 бизнес-метрики — с ответом "что
предпринимаем при превышении порога" для каждой._

## 2. Алерты (5–7)

_Каждый — как пользовательский симптом, с порогом, severity, вероятной причиной и реакцией._

## 3. Логи и трейсы

_Обязательные поля лога, сквозной trace через синхронный + асинхронный путь, sampling._
